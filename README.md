# Vishal Singh | Portfolio

Backend-focused full stack developer portfolio. Live at https://vishal368-singh.github.io/

Single page, no build step: plain HTML, CSS and JavaScript. Responsive, dark mode, reduced-motion friendly.

## Files
- `index.html` the whole site
- `resume.pdf` linked from the Download Resume buttons
- `.github/workflows/pages.yml` auto deploys on every push to `main`
- `404.html`, `favicon.svg`, `robots.txt`, `sitemap.xml`, `.nojekyll`

## Update the site
Edit `index.html` or replace `resume.pdf`, commit, and push to `main`. The site redeploys in about a minute.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server 8000` and visit http://localhost:8000
